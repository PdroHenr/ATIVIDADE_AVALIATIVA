# 🧼 CleanEstofados - Landing Page de Conversão

Esta é uma landing page , responsiva e de alta conversão desenvolvida para uma empresa de **Higienização e Impermeabilização de Estofados a Domicílio**. O objetivo principal do site é converter visitantes em leads qualificados 

## 🚀 Tecnologias Utilizadas

* **HTML5** – Estruturação semântica das seções.
* **CSS3 / Tailwind CSS** – Estilização moderna e layout totalmente responsivo (Mobile-First).
* **JavaScript (ES6)** – Manipulação de eventos (efeito de rolagem, menu mobile e envio de mensagens).
